تطبيق WALL-E Offline - مشروع Android

تم دمج منطق الكود المطلوب في MainActivity.kt:
- تصنيف الصور باستخدام Google ML Kit Image Labeling.
- تمييز تسميات شائعة للحيوانات والطعام والأشخاص، مع رسائل وتفاعلات للواجهة.
- تحديث مستوى الفضول وشريط التقدم.
- اختيار صورة من معرض الهاتف عبر الزر؛ الكاميرا المباشرة ليست مفعّلة في هذه النسخة.
- استخدام اعتماد ML Kit المضمّن داخل التطبيق: com.google.mlkit:image-labeling:17.0.7.

طريقة إنشاء APK:
1. فك ضغط الملف.
2. افتح مجلد WALLE_Offline_Android في Android Studio على كمبيوتر.
3. انتظر مزامنة Gradle وتنزيل الاعتمادات (الإنترنت مطلوب عادةً أثناء البناء الأول).
4. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. انقل APK إلى هاتف Android وثبّته.

متطلبات البناء:
- Android Studio حديث
- JDK 17
- Android SDK Platform 35
- minSdk 23 (Android 6.0)

مهم:
- هذا مشروع مصدر وليس APK جاهزًا للتثبيت.
- لم يتم التحقق من بناء APK في هذه البيئة لعدم توفر Android build toolchain.
- التصنيف عام وقد لا يتعرف بدقة على كل حيوان أو نوع طعام، كما أن تسمية الشخص ليست تعرّفًا على الهوية.
- لأن المكتبة تستخدم نموذجًا مضمّنًا في التطبيق، لا يلزم تنزيل نموذج منفصل وقت تشغيل التصنيف؛ لكن يلزم الإنترنت غالبًا لتنزيل الاعتمادات أثناء بناء المشروع.
